# 电能质量管理中心软件需求分析

## 1. 文档定位

本文面向“轻量化项目演示系统”的需求分析阶段，依据《电能质量监测系统项目技术要求.docx》中“3.1 电能质量管理中心”及相关总体目标、建设范围、接口与报表要求整理。

本阶段明确忽略原技术要求中的国产自主可控相关约束，不限定服务器、CPU、操作系统、浏览器、数据库、中间件或开发框架品牌。系统设计目标调整为：以低成本、高可行、快速可演示为优先，尽量用模拟数据、轻量部署和可视化界面还原原文档要求的业务能力。

## 2. 总体目标

电能质量管理中心软件作为场区级监控与分析平台，位于“管理中心级 - 变电站级”二层架构的上层，负责汇聚各变电站电能质量与配电运行数据，并完成展示、查询、分析、评估、报表、复盘、网络管理和对外接口。

演示版应体现以下目标：

- 展示 6 个变电站的全网供电态势。
- 支持管理中心查看各站运行状态、电能质量、告警和历史数据。
- 支持重要工作阶段的流程化态势展示和保障复盘。
- 支持谐波、负载率、温度、功率等全网分析。
- 支持统计报表、人员管理、网络管理和第三方接口演示。
- 预留 110kV 中心变电站、35kV 电站数据接口占位。

## 3. 用户与使用场景

### 3.1 主要用户

- 数据中心值班人员：查看全网供电态势、告警、关键电参数和重要工作保障状态。
- 供电系统管理人员：查询历史数据、统计报表、复盘报告和保障评估结果。
- 系统维护人员：维护网络设备、站点接入、通信状态和第三方接口配置。
- 领导或演示观摩人员：通过大屏查看全息化态势、全网风险、告警事件和保障成果。

### 3.2 典型场景

- 日常监测：中心大屏展示各变电站运行状态、电能质量概览、通信状态和告警数量。
- 重要工作阶段保障：用户按时间轴选择重点回路和关键电参数，系统突出显示相关供电路径和实时数据。
- 指定变电站查看：从全网态势下钻到某一变电站，查看组态图、设备状态、告警和历史曲线。
- 电能质量分析：按时间范围分析谐波分布、负载率、温度、平均功率等指标。
- 保障复盘：选择某次工作阶段，自动汇总过程数据、告警、趋势和评估结论，生成复盘报告。
- 对外展示或集成：通过接口输出整体电能态势、告警、报表和复盘结果。

## 4. 系统边界

### 4.1 范围内

- 管理中心大屏和 Web 管理界面。
- 全网态势展示、重要工作阶段展示、指定变电站展示。
- 告警监控、统计报表、分析评估、工作保障复盘。
- 岗位人员管理、网络管理、对外接口、第三方软件接入演示。
- 与变电站级系统的数据交互模型。

### 4.2 范围外

- 真实硬件采购、安装和布线。
- 真实 ION7650、UPS、继保、温控设备协议接入。
- 高精度建筑级三维数字孪生建模。
- 真实 SOE 2ms 硬件级时序精度验证。
- 长周期 MTBF、MTTR 可靠性试验。
- 国产自主可控适配与认证。

## 5. 总体架构需求

管理中心软件应体现二层架构中的中心级能力：

- 管理中心级：汇聚和存储各变电站数据，完成分析、评估、展示和报表。
- 变电站级：采集本站数据并向管理中心上传标准化数据。

演示版可采用单机部署方式，但界面和数据模型应表现出“中心 - 多站点”的逻辑关系。

### 5.1 逻辑组成

- 访问终端：用于管理人员、值班人员、演示人员访问系统。
- Web 服务：提供中心大屏、业务页面、查询分析和报表功能。
- 数据服务：存储站点、设备、回路、实时数据、历史数据、事件、告警和报表。
- 实时通信服务：向前端推送站点状态、实时电参量、告警和通信状态。
- 第三方接口服务：对外输出数据中心需要的态势、告警、报表和复盘结果。

### 5.2 数据来源

演示版数据来源以模拟数据为主：

- 6 个变电站基础数据。
- 各站变压器、低压进线、低压出线、UPS 出线、断路器、仪表、网关等对象。
- 电压、电流、功率、功率因数、频率、电能、谐波、闪变、三相不平衡等电能质量数据。
- 开关状态、跳闸、过流、温度、通信异常、网络告警等事件。

## 6. 功能需求

### 6.1 全息化场景展示

对应原文档“3.1.3.1 配电保障全息化场景展示”。

需求：

- 支持全网展示、重要工作阶段展示、指定变电站展示三种模式。
- 全网展示应显示 6 个变电站、站点间逻辑拓扑、站点通信状态、负载状态和告警状态。
- 重要工作阶段展示应提供流程生成或配置能力，用户可按时间轴配置阶段节点。
- 用户可在阶段节点中选择重点变电站、重点回路和重点电参数。
- 进入阶段展示后，系统应突出显示当前节点关注对象，并展示相关实时数据。
- 指定变电站展示应支持从中心访问某一站组态图，并展示该站关键运行信息。

演示实现要求：

- 采用轻量二维拓扑为主。
- 三维部分可用简化机柜、设备块或透视模型表达“数字装配、数据驱动”效果。
- 不要求真实全息投影或高精度三维建模。

### 6.2 可视化配电监控

对应原文档“3.1.3.2 可视化配电监控”。

需求：

- 基于组态图展示各变电站配电系统。
- 支持展示变电站配电设备布置。
- 支持展示配电柜、配电回路、开关状态和主要电参数。
- 支持从全网视图下钻至站级视图。
- 支持通过颜色、图标、状态标签表达运行、异常、离线、告警等状态。

演示实现要求：

- 以二维一次系统图和站点拓扑图为主要展示方式。
- 三维视图只需表达设备位置、状态和关键指标，不做复杂模型。

### 6.3 可视化配电告警

对应原文档“3.1.3.3 可视化配电告警”。

需求：

- 当发生开关跳闸、过电流、变压器高温等异常时，系统应弹窗显示告警信息。
- 告警应在全网拓扑和站级组态中同步标识。
- 告警列表应包含时间、站点、设备、回路、告警类型、等级、状态和处理人。
- 支持告警确认、处理状态更新和历史查询。

演示告警类型至少包括：

- 开关跳闸。
- 过电流。
- 变压器高温。
- 电压暂降。
- 电压超限。
- 谐波超标。
- 通信异常。

### 6.4 工作保障复盘

对应原文档“3.1.3.4 工作保障复盘”。

需求：

- 支持重要工作阶段复盘报告模板。
- 用户可选择某一次已完成的重要工作阶段。
- 系统应调取该阶段内的配电数据、告警事件、关键回路状态和关键参数趋势。
- 系统应自动生成复盘报告。
- 报告应可导出或供第三方软件接收处理。

演示版报告内容建议包括：

- 工作阶段名称、起止时间、关注站点和回路。
- 关键电参数趋势摘要。
- 告警事件清单。
- 负载率、谐波、电压异常、闪断等风险统计。
- 系统自动生成的保障结论。

### 6.5 供电保障评估

对应原文档“3.1.3.5 供电保障评估”。

需求：

- 提供保障评估方法配置能力。
- 评估方法应支持选择评估要素和权重或规则。
- 系统根据评估要求检索历史数据和事件记录。
- 系统自动生成供电保障评估表。

演示评估要素建议包括：

- 变压器负载率。
- 谐波超标次数。
- 电压暂降、超压、欠压次数。
- 开关跳闸次数。
- 通信异常次数。
- 重要回路运行连续性。

### 6.6 统计报表

对应原文档“3.1.3.6 统计报表”及表 2 系统报表。

需求：

- 支持按指定时段、指定范围统计有功电量、无功电量。
- 支持按指定时段、范围、间隔、参量生成报表。
- 支持备品备件出入库清单统计。
- 支持维修维护报表统计。
- 支持报表预览、导出、打印。

系统报表类型应覆盖：

- 系统故障报警。
- 操作日志。
- 电压骤升骤降事件分析。
- 电压瞬时事件分析。
- 电压、电流、功率、频率等原始数据报表。
- 电压、电流、功率、频率等最大值、最小值、平均值、95% 概率值、允许值、合格率报表。
- 谐波电压、电流最大值、最小值、平均值、95% 概率值、允许值、合格率报表。
- 电压偏差报表。
- 电能质量综合报表。
- 谐波电压、电流总畸变率。
- 各次谐波电流有效值。
- 电压、电流三相不平衡度。
- 电流各序分量。
- 电压长时闪变、短时闪变。

### 6.7 电能质量分析评估

对应原文档“3.1.3.7 电能质量分析评估”。

需求：

- 提供谐波分析工具。
- 支持分析变电站至用户端的全网谐波分量分布。
- 支持按时间范围和谐波次数搜索该时间域内谐波分量最大时刻。
- 支持在全网拓扑上以颜色热力方式展示谐波分布。
- 提供负载分析工具。
- 支持按时间范围分析各变压器平均负载率。
- 支持按时间范围分析各变压器平均温度。
- 支持按时间范围分析各变电站平均功率。
- 支持以拓扑颜色热力方式展示分析结果。

演示实现要求：

- “彩色等值线”可用拓扑热力色带、站点色阶、回路颜色映射方式模拟。
- 分析数据可来自模拟历史数据。

### 6.8 岗位人员管理

对应原文档“3.1.3.8 岗位人员管理”。

需求：

- 支持供电岗位人员信息录入与维护。
- 支持岗位值班人员签到。
- 支持点名记录。
- 支持值班人员当班记录。
- 支持按人员、岗位、时间范围统计查询。

### 6.9 网络管理

对应原文档“3.1.3.9 网络管理”及建设范围中网络管理模块要求。

需求：

- 对配电系统范围内设备通信状态进行管理。
- 支持设备 IP 地址、站点、设备类型、通信协议、在线状态管理。
- 支持查看某个设备通信状态和数据报文示例。
- 支持通信异常告警。
- 支持网络拓扑展示。

演示边界：

- 控制功能仅模拟，不执行真实网络设备控制。
- 报文查看可展示模拟报文或最近一次采样数据。

### 6.10 对外接口

对应原文档“3.1.3.10 对外接口”。

需求：

- 预留外部数据通信接口。
- 支持将电能系统数据接入至其他外网或数据中心系统。
- 演示版应提供 JSON 格式接口。
- 接口数据至少包括站点状态、实时数据、告警、事件、报表和复盘报告。

### 6.11 第三方软件接入

对应原文档“3.1.3.11 第三方软件接入”。

需求：

- 支持整体电能态势接入数据中心监控系统。
- 支持站级系统接入 UPS 设备运行管理软件、UPS 电池监测软件、高压配电继保系统软件等。
- 对通信协议开放的软件，采用数据通信方式获取信息。
- 对通信协议不开放的软件，采用调用或链接方式汇聚到同一应用平台。

演示边界：

- 提供第三方系统接入配置页面和模拟接口。
- 不接入真实第三方系统。
- 保留协议适配层扩展说明。

## 7. 数据需求

### 7.1 站点数据

每个站点应包含：

- 站点编号。
- 站点名称。
- 站点类型。
- 通信状态。
- 总负荷。
- 告警数量。
- 电能质量综合状态。
- 经纬度或拓扑坐标。
- 是否预留站点。

### 7.2 设备与回路数据

中心侧应能汇总展示以下对象：

- 变压器。
- 低压进线。
- 低压出线。
- UPS 出线。
- 配电柜。
- 断路器。
- ION7650 电能质量仪表。
- 数显仪表。
- 边沿计算网关。
- 交换机。
- 本地站服务器。

### 7.3 实时数据

应支持管理中心查看：

- 三相电压。
- 三相电流。
- 有功功率。
- 无功功率。
- 视在功率。
- 功率因数。
- 频率。
- 有功电能。
- 无功电能。
- 谐波电压。
- 谐波电流。
- 三相不平衡度。
- 闪变。
- 变压器温度。
- 开关状态。

### 7.4 事件与告警数据

应支持：

- 电压暂降。
- 电压暂升。
- 电压瞬态。
- 供电闪断。
- 断路器跳闸。
- 过电流。
- 变压器高温。
- 谐波超标。
- 设备故障。
- 网络通信告警。

## 8. 接口需求

### 8.1 中心对站级接口

中心应能接收或查询站级数据：

- 站点状态。
- 设备状态。
- 实时电参量。
- 历史曲线。
- 电能质量指标。
- 告警事件。
- 运维记录。
- 报表数据。

演示版可用本地模拟服务替代真实站级接口。

### 8.2 中心对外接口

应提供：

- 态势总览数据接口。
- 站点实时状态接口。
- 告警事件接口。
- 报表导出接口。
- 复盘报告导出接口。
- 第三方系统模拟接入接口。

### 8.3 实时推送

应支持实时推送：

- 全网站点状态。
- 设备状态变化。
- 实时电参量变化。
- 新告警。
- 通信状态变化。

## 9. 非功能需求

### 9.1 演示性能

- 实时数据刷新周期建议不大于 2 秒。
- 数字量状态变化推送建议不大于 1 秒。
- 动态画面响应建议不大于 2 秒。
- 单机演示应保证页面切换流畅、图表加载可接受。

### 9.2 易用性

- 第一屏应直接进入全网态势，不做营销式首页。
- 大屏信息应层次清晰，便于值班人员快速判断风险。
- 告警、站点、设备、回路应支持快速下钻。
- 报表和复盘应能一键生成演示结果。

### 9.3 可扩展性

- 后续应能替换模拟数据为真实采集数据。
- 后续应能增加真实协议适配，如 Modbus、OPC UA、MQTT 等。
- 后续应能扩展更多变电站、设备和回路。

### 9.4 安全与权限

演示版应至少体现：

- 用户、角色、权限模型。
- 操作日志。
- 重要配置修改留痕。
- 告警确认和处理记录。

## 11. 待确认事项

- 6 个演示变电站是否需要使用真实名称，还是使用“电站 1～电站 6”。
- 大屏演示分辨率是否固定，例如 1920x1080、2K 或拼接屏。
- 复盘报告是否需要按甲方既有模板输出。
- 对外接口是否需要提前约定字段名称和示例 JSON。
- 是否需要将管理中心和变电站软件做成两个独立入口，还是同一系统内按角色和菜单区分。
