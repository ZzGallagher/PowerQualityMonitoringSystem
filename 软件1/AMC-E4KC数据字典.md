# AMC-E4KC 数据字典与采集约定

## 1. 采集口径

第一版演示采用 AMC(II)-E4KC 手册第 6 章的 Modbus-RTU 协议，使用 `03` 功能码只读寄存器。电参量优先读取二次侧寄存器，避免一次侧 `DPT/DCT/DPQ` 与符号位换算在现场联调阶段引入额外不确定性。

谐波能力暂不承诺真实采集。`0400H` 起的 THD 与 2-31 次谐波寄存器进入点表字典，但默认质量状态为 `unsupported`，前端应显示“仪表谐波功能未确认/暂未接入”，不得生成假谐波曲线。

## 2. 第一版读取块

| 读取块 | 起始地址 | 数量 | 用途 |
| --- | ---: | ---: | --- |

## 4. 数据包约定

软件1发送给软件2时，每个点位必须使用上表 `code`，不得在软件2中再做字段重命名。推荐点位对象：

```json
{
  "code": "ua",
  "name": "A相电压值",
  "value": 220.1,
  "rawValue": 2201,
  "unit": "V",
  "quality": "good",
  "source": "amc-e4kc-secondary",
  "timestamp": "2026-05-21T14:30:00+08:00"
}
```

质量状态：

- `good`：正常采集并换算成功。
- `stale`：数据超过刷新周期但未超过离线阈值。
- `timeout`：Modbus 请求超时。
- `crc_error`：响应 CRC 校验失败。
- `parse_error`：响应长度、功能码或数据类型解析失败。
- `out_of_range`：换算值超出合理范围。
- `unsupported`：仪表能力未确认或不支持，例如第一版谐波。
- `not_connected`：组态对象未接入真实数据源。

## 5. 现场联调检查单

1. 确认仪表从站地址、波特率、校验位、数据位和停止位。
2. 使用 `AMC-E4KC最小Modbus读取验证.ps1` 先读取 `0100H-011BH`。
3. 将电压、电流、功率、功率因数、频率与仪表屏幕逐项对照。
4. 再验证 `0022H`、`008CH-008EH`、`0700H-0701H`、`003FH-0040H`。
5. 若功率单位与仪表屏幕口径不一致，优先修正点表中的展示单位，不修改字段编码。
6. 谐波页面仅展示未接入/不支持，不生成随机值或演示假曲线。
