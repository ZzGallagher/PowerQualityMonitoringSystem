# 软件2低压组态监测前端

这是软件2的轻量 Web 前端原型，默认入口为 `index.html`。

## 已实现

- 9 个一级页面导航，已合并“本站态势”和“实时监测”为“低压组态监测”。
- 组态图不再使用图片底图，改为由 `topology-config.js` 配置驱动生成 SVG。
- 柜体、母线、回路、补偿柜、进线柜、联络柜、通讯状态文字和实时三相电流均由代码绘制。
- 开关柜回路旁显示 Ia/Ib/Ic 实时电流，避免把图纸示例 `10.00A` 当作真实值展示。
- 默认按 150% 展示，支持放大、缩小和适屏；长图可通过横向滚动条左右查看。
- 支持双击回路弹出实时信息窗口。
- 新增“变电站可视化”页面，使用本地 Three.js 加载 AA1 三维模型，并联动四个回路通断状态。
- 按 `dSSCCNN` 规则生成内部回路编号，例如 `d010205` 表示 01 号站 AA02 柜 05 号抽屉。
- 回路显示名称保留表格/图纸原文，同柜重复名称不追加序号。
- 绑定仪表且已收到实时数据的回路显示绿色“通讯正常”；未绑定或未收到数据的回路显示红色“通讯异常”。

## 文件说明

- `index.html`：页面入口。
- `topology-config.js`：低压柜、回路、仪表绑定和画布尺寸配置。
- `app.js`：导航、SVG 组态图渲染、回路模型、弹窗和实时刷新逻辑。
- `substation-3d.js`：AA1 三维模型加载、视角控制和开关状态联动逻辑。
- `styles.css`：布局、导航、SVG 图元、缩放控件和弹窗样式。
- `assets/models/AA1.glb`：由根目录 `AA1.blend` 导出的浏览器模型文件。

## 使用方式

普通二维页面可直接在浏览器打开 `index.html`。三维页面使用 ES Module 和 glTF 资源，建议在本目录启动静态服务后访问页面。
