# 软件2：数据接收展示与站级前端软件任务书

## 1. 文档定位

本文面向轻量版演示系统的软件2开发工作。软件2负责接收软件1发送的数据包，存储实时与历史数据，并提供单变电站的 Web 前端展示、告警、查询、报表、抄表、设备管理和接口管理能力。

本任务书依据以下资料整理：

- 《../需求类文档/变电站电能质量监测软件需求分析.md》
- 《../需求类文档/电能质量监测系统项目技术要求.docx》
- 《../参考文档/电能质量项目采集网关设备数据输出内容V1.4.doc》
- 《../参考文档/组态图.pdf》

演示边界：

- 仅展示一个变电站。
- 真实数据来源仅为一台 AMC 电力仪表。
- 一次图中的高压柜、低压柜、开关、补偿柜、联络柜等对象作为组态对象展示。
- 未接入的断路器状态、UPS、继保、温控等数据可作为演示数据或配置态，但界面和数据质量字段应明确区分真实采集、模拟和未接入。
- 暂不建设管理中心多站大屏，但预留站级向中心上传的数据接口模型。

## 2. 建设目标

软件2应形成一个可现场演示的站级轻量 Web 系统，实现如下目标：

- 接收并解析软件1发送的数据包。
- 展示本站一次组态图和关键电参量。
- 将 AMC 实时数据映射到指定柜体、回路或仪表对象。
- 支持实时监测、告警提示、历史曲线、事件查询。
- 支持设备档案、接口状态、运行报表、定时抄表和统计分析的演示闭环。
- 支持后续扩展更多仪表、更多站点和管理中心接口。

软件2应提供“仪表数据映射配置”：

- 将 `amc-001` 映射到一个默认监测点，例如低压主进线柜 AA5 或现场实际接入回路。
- 支持后续修改映射关系。
- 页面上应显示该点数据来源为“真实 AMC 采集”。
- 其他未接入对象显示为“未接入”“配置态”或“演示数据”，避免误导。

## 4. 总体架构

软件2建议采用轻量 B/S 架构：

- 数据接收服务：接收软件1数据包。
- 数据处理服务：校验、入库、派生计算、告警规则判断。
- 数据存储：站点、设备、点位、实时值、历史值、统计值、告警、事件、报表。
- 实时推送：向前端推送实时数据、告警和通信状态。
- Web 前端：一次图、监测页面、查询分析、报表、管理页面。

可采用单体应用实现，但模块边界应清晰，便于后续拆分。

## 5. 功能任务分解

### S2-01 数据包接收与校验

开发内容：

- 提供 `POST /api/ingest/packets` 接口。
- 支持接收 heartbeat、realtime、statistics、alarm、event、comm_status 数据包。
- 校验协议版本、包类型、站点、网关、仪表、序号、时间戳和载荷。
- 识别重复包、乱序包和缺包。
- 保存原始数据包摘要，便于联调追溯。
- 返回明确的接收结果和错误原因。

验收标准：

- 能接收软件1真实数据包。
- 错误包不会影响服务稳定性。
- 接收状态可在接口管理页面查看。

### S2-02 站点、设备与点位模型

开发内容：

- 建立站点、柜体、回路、仪表、网关、点位、数据源模型。
- 建立高压 AA1-AA7、低压 AA0-AA11 的默认组态对象。
- 直接复用《../软件1/AMC-E4KC数据字典.md》和《../软件1/AMC-E4KC点表-v1.json》中的 AMC 字段编码，建立 AMC 必采字段点位字典。
- 支持点位与柜体/回路/仪表对象绑定。
- 支持数据质量字段：真实、模拟、未接入、异常、离线。

验收标准：

- 首次启动后自动生成演示站点基础数据。
- AMC 数据能在所绑定的柜体或回路上展示。
- 组态对象可查询、可维护。

### S2-03 实时数据处理与存储

开发内容：

- 保存最新实时值。
- 保存历史采样值。
- 保存 3 秒统计数据的最大值、最小值、平均值。
- 支持按设备、回路、参数、时间范围查询。
- 支持数据保留周期配置。
- 支持通信状态、数据新鲜度、质量码判断。

验收标准：

- 实时页面刷新周期不大于 2 秒。
- 历史曲线可查询最近采集数据。
- 仪表离线后页面能显示数据过期或离线状态。

### S2-04 一次图与电力态势显示

开发内容：

- 第一屏直接展示本站一次图，不做营销式首页。
- 以《../参考文档/组态图.pdf》为依据，绘制轻量二维一次系统图。
- 展示高压柜、低压柜、主进线、母联、负荷柜、电容补偿柜等对象。
- 对绑定 AMC 的对象实时显示关键指标。
- 支持颜色表达运行、告警、离线、未接入、模拟数据状态。
- 支持点击设备弹出详情。

关键实时指标：

- 三相电压、线电压。
- 三相电流。
- 有功功率、无功功率、视在功率。
- 功率因数。
- 频率。
- 吸收有功电能。
- 电压/电流不平衡度。
- 零序电压、零序电流。

验收标准：

- 用户打开系统后能立即看到本站一次图和 AMC 实时数据。
- AMC 数据变化能在图上或关键指标区及时更新。
- 未接入对象有明确视觉区分。

### S2-05 电参量详情与历史查询

开发内容：

- 点击 AMC 仪表或绑定回路，弹出实时电参量详情。
- 支持选择时间范围查询历史曲线。
- 支持电压、电流、功率、功率因数、频率、电能、不平衡度曲线。
- 支持统计值展示：最大值、最小值、平均值、出现时间。
- 支持导出查询结果。

验收标准：

- 可查询任意已采集参数的历史曲线。
- 曲线数据与数据包入库记录一致。
- 查询条件清晰，空数据时提示友好。

### S2-06 告警与事件管理

开发内容：

- 建立阈值规则：电压越限、电流越限、频率越限、功率因数偏低、三相不平衡超限、通信中断。
- 接收软件1生成的告警，也支持软件2根据实时值二次判断告警。
- 新告警弹窗提示。
- 一次图对应对象闪烁或高亮。
- 支持告警确认、处理说明、关闭。
- 保存告警全生命周期。
- 支持事件查询：通信中断/恢复、开关量变化、越限、恢复、手动确认。

验收标准：

- 新告警能在 2 秒内出现在前端。
- 告警列表包含时间、设备、回路、类型、等级、状态、处理人。
- 告警确认和处理记录可追溯。

### S2-07 报表与定时抄表

开发内容：

- 支持运行报表生成。
- 支持供电数据报表：报表时段、运行时长、总有功电能、平均功率因数、最大负荷、最大电流、三相不平衡最大值等。
- 支持运行状态评估报表：是否出现通信中断、越限、谐波/闪变未接入说明、整体评价。
- 支持值班人员报表和运维报表的基础录入与查询。
- 支持定时抄表配置：站点、数据项、起始时刻、间隔、分页方式。
- 默认生成每次 1 页的电子抄表记录，预留打印入口。
- 支持导出 PDF 或 Excel，若开发周期有限，优先导出 HTML/PDF。

验收标准：

- 可选择时间范围生成演示报表。
- 抄表记录包含 AMC 关键电参量和电子签字栏。
- 报表中的未接入指标应明确标注“不适用/未接入”。

### S2-08 统计分析与故障分析

开发内容：

- 提供负载分析：有功功率、电流、功率因数、不平衡度趋势。
- 提供电能质量分析：基于 AMC 已采字段展示电压偏差、不平衡度、频率偏差。
- 对谐波、闪变、暂降暂升等 AMC 未提供或未接入数据，提供接口占位和未接入说明。
- 提供规则化故障分析结论，例如过流、电压越限、通信中断、三相不平衡。
- 支持选择告警事件查看前后数据趋势。

验收标准：

- 可围绕一次告警查看前后过程数据。
- 分析结论使用规则生成，并展示依据数据。
- 未接入的电能质量项目不伪造真实数据。

### S2-09 设备管理

开发内容：

- 设备档案字段：名称、柜号、类型、型号规格、主要参数、厂家、生产日期、说明文档、供电用户名称、标称负荷、相别、电压等级、需要系数。
- 支持 AMC 仪表、笔记本网关、RS485 转 USB、柜体、回路档案。
- 支持维护记录新增、查询、导出。
- 支持设备状态：运行、告警、离线、未接入、停用。

验收标准：

- 能从一次图点击设备进入档案。
- 能维护 AMC 和网关基础信息。
- 维护记录可追加并留痕。

### S2-10 接口管理

开发内容：

- 展示软件1到软件2的数据接入拓扑。
- 展示网关、串口、仪表、接收接口的通信状态。
- 展示最近数据包时间、包类型、序号、解析结果。
- 提供数据词典查看。
- 提供 AMC 点位映射查看。
- 预留管理中心上传接口和第三方系统接入接口。

验收标准：

- 联调时可通过页面判断软件1是否在线、是否正在上报。
- 接口异常能生成通信告警。
- 数据词典与前端展示字段一致。

### S2-11 系统管理

开发内容：

- 用户、角色、权限的轻量模型。
- 人员管理：姓名、单位、部门、职务、电话、数据权限。
- 值班人员记录。
- 字典值管理。
- 业务参数管理：阈值、刷新周期、报表参数、抄表周期。
- 操作日志：登录、配置修改、告警确认、报表生成、维护闭环。

验收标准：

- 至少支持管理员和值班员两类角色。
- 重要操作可在日志中查询。
- 告警阈值可配置并即时或重启后生效。

## 6. 页面清单

软件2前端至少包含以下页面。本站态势与实时监测合并为“低压组态监测”，默认进入该页面，在动态组态图上完成低压侧一次图展示、回路交互和实时数据查看。

| 页面 | 主要内容 | 优先级 |
| --- | --- | --- |
| 低压组态监测 | 低压侧 PDF 组态图、透明回路热区、关键指标、告警摘要、通信状态、双击回路实时信息 | P0 |
| 历史曲线 | 参数选择、时间范围、曲线和统计值 | P0 |
| 告警事件 | 告警列表、确认、处理、事件查询 | P0 |
| 接口管理 | 网关状态、数据包记录、点位字典 | P0 |
| 报表抄表 | 运行报表、定时抄表、导出 | P1 |
| 统计分析 | 负载、电压偏差、不平衡、频率分析 | P1 |
| 设备管理 | 设备档案、维护记录 | P1 |
| 系统管理 | 用户、角色、阈值、字典、日志 | P2 |
| 第三方接入 | UPS、继保、温控、管理中心接口占位 | P2 |

低压组态监测实现约定：

- 网页版组态图采用配置驱动 SVG 绘制，不使用图片作为底图；柜体、母线、回路、符号、状态点和实时数值均由配置与代码生成。
- `./参考文档/组态图.pdf` 作为低压侧布局和符号的参考依据，配置文件应表达柜体顺序、回路清单和仪表绑定关系，便于后续复用到其他电站长图。
- 图纸中的示例数值（如各回路旁的 `10.00A`）不得作为最终实时显示值使用，页面应在对应回路位置显示该回路三相电流，并随采集数据刷新。
- 回路清单来自 `./参考文档/低压配电柜说明.xlsx`。AA0、AA1、AA2、AA9、AA10 按抽屉建立多个回路；补偿柜、联络柜、进线柜视为单回路。
- 内部回路编号采用 `dSSCCNN`，其中 `SS` 为站点编号，`CC` 为 AA 柜号数字，`NN` 为柜内回路/抽屉序号。例如 `d010205` 表示 01 号电站 AA02 柜 05 号抽屉。
- 前端展示回路名称完全沿用图纸/表格原文，同柜内重名不追加序号，由内部回路编号保证数据处理唯一性。

## 12. 验收场景

基础联调：

- 软件1连接真实 AMC 仪表。
- 软件2显示网关在线、仪表在线。
- 本站态势页显示 AMC 实时电压、电流、功率、功率因数、频率和电能。

通信异常：

- 断开 RS485 或停止软件1。
- 软件2在超时时间后显示通信异常并产生告警。
- 恢复连接后状态恢复，历史事件可查询。

阈值告警：

- 通过真实数据、模拟模式或测试包触发越限。
- 前端弹窗，一次图对象高亮，告警进入待处理。
- 值班员确认并填写处理说明。

历史查询：

- 选择 AMC 电压、电流、功率等参数。
- 查询最近一段时间曲线。
- 显示最大值、最小值、平均值和时间。

报表抄表：

- 生成一个时段运行报表。
- 生成一页式抄表记录。
- 报表中真实采集项、未接入项标识清晰。

## 13. 待确认事项

- AMC 实际接入点对应组态图中的哪个柜体或回路。
- 前端是否需要完全复刻 PDF 图形，还是允许按 Web 交互重新绘制。
- 报表导出优先格式：PDF、Excel、HTML。
- 演示时是否需要大屏模式。
- 是否需要软件2同时内置软件1模拟数据源，便于无仪表演示。
